# 需求文档 - spec016.5-事务工作台画布化与插件块布局

状态：Draft

## 简介

这份需求解决的是事务视图的主舞台问题。

用户不是想在事务模式里多一个分区，而是想把常看的东西收成一个真正能停留的工作台：

- 左边保留导航
- 左边下方保留固定快捷应用栏
- 右边是一整块完整画布
- 顶部用标签页切换不同工作台
- 画布里摆代办、自动化、统计插件、HTML 页面块

## 术语表

- **事务工作台**：事务视图里的正式主入口，承担画布式工作区。
- **工作台画布**：事务视图右侧整块区域，不再拆成中间区和右侧常驻详情区。
- **工作台标签页**：画布顶部的标签工具栏，每个标签页对应一套画布布局。
- **工作台块**：画布上的独立内容块，比如代办块、自动化块、HTML 统计块。
- **快捷应用栏**：左侧菜单下方的固定区域，用来挂常用静态 HTML 应用入口。
- **静态 HTML 快捷应用**：工作区里的静态 HTML 文件，被登记后作为应用入口显示。

## 范围说明

### In Scope

- 左侧“代办”“自动化”合并成“工作台”
- 左侧导航默认显示
- 事务视图默认取消右侧常驻边栏
- 工作台画布占满原中间区 + 右侧区
- 画布顶部标签页切换、创建、重命名、删除、排序
- 画布块的添加、移动、缩放、删除、恢复默认布局
- 左侧固定快捷应用栏
- 从工作区静态 HTML 文件添加快捷应用入口
- HTML 统计插件块、HTML 页面嵌入块、静态 HTML 应用块的边界约束
- 布局和快捷应用配置的持久化与恢复

### Out of Scope

- 文档库主页面重做
- 多人协同编辑工作台
- 任意外部网页无限制嵌入
- 万能低代码编排器
- 继续保留默认右侧助手栏

## 需求

### 需求 1：事务视图左侧收口成正式“工作台”入口

**用户故事：** 作为事务模式用户，我希望左侧把代办和自动化收成一个“工作台”，这样我进入的是统一主区，而不是两个割裂页面。

#### 验收标准

1. WHEN 用户进入事务模式 THEN System SHALL 在左侧显示正式“工作台”入口，并替代原本长期并列存在的“代办”“自动化”一级入口。
2. WHEN 用户点击“工作台” THEN System SHALL 打开工作台画布，而不是旧的单列表页。
3. WHEN 用户从旧版本状态恢复 THEN System SHALL 把旧的 `todo` 或 `automation` 状态迁移到“工作台”默认标签页。

### 需求 2：事务视图默认没有右侧常驻边栏

**用户故事：** 作为事务模式用户，我希望进入工作台时先看到完整画布，而不是被右侧详情栏长期挤占空间。

#### 验收标准

1. WHEN 用户进入事务工作台 THEN System SHALL 默认不渲染右侧常驻详情/助手栏。
2. WHEN 用户处在工作台视图 THEN System SHALL 让原来的中间区和右侧区组成一整块画布区域。
3. WHEN 后续需要展示详情或助手信息 THEN System SHALL 通过独立的次级交互承载，而不是恢复默认常驻右栏。

### 需求 2.1：左侧导航默认显示

**用户故事：** 作为事务模式用户，我希望一进入事务视图就能看到左侧导航，不需要多一步先展开。

#### 验收标准

1. WHEN 用户进入事务模式 THEN System SHALL 默认显示左侧导航栏。

### 需求 2.2：文档、对话、工作台三种分区的右侧栏规则不同

**用户故事：** 作为事务模式用户，我希望文档视图保留对象详情，但对话和工作台不要长期占着右侧栏。

#### 验收标准

1. WHEN 用户处在文档视图 THEN System SHALL 默认显示右侧边栏，并展示对象详情。
2. WHEN 用户处在对话视图 THEN System SHALL 默认不显示右侧边栏。
3. WHEN 用户处在工作台视图 THEN System SHALL 默认不显示右侧边栏。

### 需求 3：工作台画布顶部支持多个标签页

**用户故事：** 作为事务模式用户，我希望一个工作区能有多个工作台标签页，按不同场景切换不同布局。

#### 验收标准

1. WHEN 用户进入工作台 THEN System SHALL 在整块画布顶部显示标签工具栏。
2. WHEN 用户新建、重命名、删除或排序标签页 THEN System SHALL 保存变更，并在重新进入时恢复。
3. WHEN 用户删除当前标签页且仍有其他标签页 THEN System SHALL 自动切到一个合法标签页。

### 需求 4：工作台画布支持块式布局

**用户故事：** 作为事务模式用户，我希望把代办、自动化和 HTML 内容按块摆在画布里，并调整大小和位置。

#### 验收标准

1. WHEN 用户添加块 THEN System SHALL 在当前标签页画布里创建块，并分配默认位置和尺寸。
2. WHEN 用户拖动或调整块大小 THEN System SHALL 更新布局，并在刷新或重进后恢复。
3. WHEN 单个块配置无效或加载失败 THEN System SHALL 只让当前块报错，不拖垮整张画布。

### 需求 5：左侧固定快捷应用栏支持静态 HTML 应用入口

**用户故事：** 作为事务模式用户，我希望把工作区里的静态 HTML 文件挂到左侧固定应用栏，方便一键打开常用工具。

#### 验收标准

1. WHEN 用户在工作区里选择一个可接受的静态 HTML 文件 THEN System SHALL 允许把它添加到左侧固定快捷应用栏。
2. WHEN 用户重新进入该工作区 THEN System SHALL 恢复快捷应用栏里的 HTML 应用入口。
3. WHEN 静态 HTML 文件路径无效、来源不合法或不满足约束 THEN System SHALL 拒绝添加，并说明原因。

### 需求 6：工作台第一阶段支持代办块和自动化块

**用户故事：** 作为事务模式用户，我希望先把代办和自动化都摆进工作台，这样不用再切来切去。

#### 验收标准

1. WHEN 用户添加代办块 THEN System SHALL 显示代办相关信息，并支持至少一种紧凑视图和一种明细视图。
2. WHEN 用户添加自动化块 THEN System SHALL 显示自动化任务或最近运行信息，并支持打开对应详情。
3. WHEN 旧事务模式已经有代办或自动化使用习惯 THEN System SHALL 在默认布局里给出等价入口。

### 需求 7：工作台支持 HTML 统计插件块和 HTML 页面嵌入块

**用户故事：** 作为事务模式用户，我希望把指标信息或专用 HTML 页面直接钉在画布里。

#### 验收标准

1. WHEN 用户添加 HTML 统计插件块 THEN System SHALL 用受控方式展示统计信息或指标信息。
2. WHEN 用户添加 HTML 页面嵌入块 THEN System SHALL 在块内打开受控 HTML 页面。
3. WHEN HTML 块运行失败、来源失效或权限不足 THEN System SHALL 在块内显示清楚错误，不影响其他块。

### 需求 8：HTML 相关来源必须受控

**用户故事：** 作为系统维护者，我希望快捷应用栏和画布里的 HTML 来源都受控，别把普通预览页和正式插件混成一锅。

#### 验收标准

1. WHEN 用户添加左侧快捷应用或画布 HTML 块 THEN System SHALL 只接受系统允许的静态 HTML 来源或正式插件来源。
2. WHEN 用户试图把普通 HTML 文件预览直接升级成插件块 THEN System SHALL 明确拒绝。
3. WHEN HTML 内容需要访问工作区资源 THEN System SHALL 继续受当前工作区边界约束。

### 需求 9：工作台状态需要稳定持久化

**用户故事：** 作为事务模式用户，我希望标签页、块布局和快捷应用入口都能记住。

#### 验收标准

1. WHEN 用户调整标签页、块布局或快捷应用栏 THEN System SHALL 在可接受时间内保存状态。
2. WHEN 用户刷新页面、关闭再打开或切换工作区回来 THEN System SHALL 恢复最近一次有效状态。
3. WHEN 恢复到损坏数据 THEN System SHALL 回退到安全默认状态，并保留可诊断信息。

## 非功能需求

### 非功能需求 1：交互性能

1. WHEN 用户拖动或缩放单个块 THEN System SHALL 保持正常交互，不出现整页明显卡死。
2. WHEN 单个标签页包含多个块 THEN System SHALL 优先局部刷新受影响块，而不是整页重渲染。

### 非功能需求 2：可靠性

1. WHEN 单个块失败 THEN System SHALL 只影响当前块。
2. WHEN 快捷应用来源缺失或 HTML 运行失败 THEN System SHALL 允许用户看到错误并移除入口，不把整个工作台卡死。

### 非功能需求 3：可维护性

1. WHEN 后续新增新的块类型或新的快捷应用来源 THEN System SHALL 允许走统一模型扩展，而不是继续往主组件堆分支。
2. WHEN 排查问题 THEN System SHALL 能从状态里分清主分区、标签页、画布块和快捷应用栏，而不是混成一个大对象。

## 成功定义

- 左侧事务导航里，“工作台”成为正式入口。
- 事务视图默认不再显示右侧常驻栏。
- 工作台画布占满原中间区 + 右侧区。
- 顶部标签栏、左侧固定快捷应用栏和画布能同时存在。
- 用户可以稳定恢复标签页、块布局和快捷应用入口。
