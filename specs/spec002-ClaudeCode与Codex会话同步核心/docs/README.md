# spec002 补充文档目录说明

本目录用于存放 `spec002` 的补充材料。主文档在同级目录：

- `requirements.md`
- `design.md`
- `tasks.md`

这里建议放的内容：

- `provider-claude-code-样本说明.md`：Claude Code 原始会话样本与字段说明
- `provider-codex-样本说明.md`：Codex 原始会话样本与字段说明
- `会话同步联调记录.md`：发现/历史/实时/续接/新建会话联调结果
- `capability-descriptor-契约样例.md`：能力描述符示例与字段解释
- `验收记录.md`：按需求逐条验收的证据链接

写作要求：

- 全部中文，先说人话再补追踪信息
- 样本可脱敏，但字段语义必须保留
- 验收记录必须带时间、环境、结果、失败原因（如有）

边界提醒：

- 不在这里写 UI 视觉方案（属于 `spec003`）
- 不在这里设计第三个 provider（属于 `spec010` 或后续 spec）
- 不在这里保存完整原始消息副本，只记录样本结构与脱敏片段
