# spec001.3.1-桌面端本机HOST自动发现

## 当前定位

这是 `spec001.3` 下的新子 Spec。

它只解决一件事：

- 在 `Windows`、`macOS` 桌面客户端里，自动发现本机已经运行中的 `codingns` Host，并把它们放进 HOST 列表里的“自动发现”分类。

一句人话：
不是继续让用户自己抄 `http://127.0.0.1:3002`，而是客户端自己先去找本机有没有已经跑起来的 Host。

## 计划覆盖

- 桌面端本机 `codingns` 进程扫描能力
- 自动发现 HOST 的运行时数据结构和 UI 展示分组
- 自动发现 HOST 与手动 HOST 的去重规则
- 自动发现 HOST 的用户名、密码本地保存规则
- 桌面端扫描触发时机、刷新时机和失败兜底

## 依赖关系

- 前置依赖：
  - `spec001-平台底座与工作区基础`
  - `spec001.3-多HOST接入与跨端切换`
- 强相关依赖：
  - `spec008-桌面端与H5交付增强`

## 本阶段明确不做

- 不做 Linux 客户端自动发现
- 不做移动端自动发现
- 不做局域网广播扫描、mDNS、Bonjour 这类网络发现
- 不把自动发现结果直接写进用户手工维护的 HOST 配置里
- 不负责自动拉起 `codingns` 进程，只负责发现已经在跑的实例
