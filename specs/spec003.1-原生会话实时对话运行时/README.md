# spec003.1-原生会话实时对话运行时

## 当前定位

这个 Spec 不是再做一个“能看历史消息的聊天页”，而是把项目真正补成可对话产品：

- 能在本项目里新建 `Claude Code` / `Codex` 原生会话
- 能实时发送消息、实时看到 AI 继续输出
- 能接着外部已经存在的原生会话继续聊
- 能保证在本项目里创建的会话，回到原生 `Claude Code` / `Codex` 里也还能继续

一句话说清楚：这一步要把“会话文件同步”升级成“真实会话运行时”。

## 计划覆盖

- Provider 真实运行时抽象
- Claude Code 原生会话实时对话
- Codex 原生会话实时对话
- 已有原生会话继续对话
- 本项目创建会话与原生环境双向互通
- 运行中会话的实时流式刷新、恢复、中断和错误回传

## 依赖关系

- 前置依赖：`spec002`、`spec003`、`spec006`、`spec010`
- 影响范围：`apps/host`、`packages/session-sync-core`、`apps/user-app`
- 后续会直接受益：文件管理、Git 上下文、终端联动、移动端会话体验

## 本阶段明确不做

- 不做第三套私有会话格式
- 不做脱离原生会话的“虚拟线程”
- 不做多 provider 混聊同一会话
- 不做新的 Provider 扩展，先把 `Claude Code` 和 `Codex` 做对
- 不把消息轮询文件尾巴伪装成实时对话
