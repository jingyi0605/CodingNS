# spec003-对话式主界面与消息运行时

## 当前定位

这个 Spec 负责把“对话是主舞台”真正做成产品结构，而不是做成后台页面里的一块聊天框。

## 计划覆盖

- 主对话视图
- 消息渲染模型
- 输入区复合操作面板
- 会话头部与上下文区
- capability 驱动的操作门控
- 消息实时更新与断线重连体验

## 依赖关系

- 前置依赖：`spec001`、`spec002`
- 后续依赖：`spec004`、`spec005`、`spec006`、`spec007`

## 本阶段明确不做

- 全量 IDE 式布局仿制
- 与 provider 耦合的页面特判散落
- 复杂团队协作 UI
