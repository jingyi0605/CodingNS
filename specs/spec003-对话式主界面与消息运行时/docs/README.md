# spec003 补充文档目录说明

本目录用于存放 spec003 的补充材料，主文档仍以 `requirements.md`、`design.md`、`tasks.md` 为准。

建议后续补充：

- `接口联调清单.md`：记录会话页依赖的 HTTP / WebSocket 接口联调结果
- `能力门控矩阵.md`：记录不同 provider / session 能力组合下的前端可见行为
- `断线重连测试记录.md`：记录网络抖动、重连失败、补偿拉取等测试结果
- `鉴权回归记录.md`：记录未登录访问拦截、token 失效恢复、WS 鉴权握手验证结果
- `验收记录.md`：按 `tasks.md` 最终检查点整理验收证据

维护规则：

- 文档用中文写清“做了什么、结果是什么、还缺什么”
- 出现阻塞时必须写明阻塞原因和下一步处理人
- 验证结论要可追踪到具体需求和任务编号
