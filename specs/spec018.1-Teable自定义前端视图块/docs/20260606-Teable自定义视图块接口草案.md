# 20260606-Teable自定义视图块接口草案

## 目标

给事务工作台 Teable 块提供一组 Host runtime API。

前端不直接请求 Teable，也不保存 Teable token。前端只请求 CodingNS Host，Host 再用已保存的 Teable 连接和 token 调 Teable API。

## API 草案

### 1. 读取表列表

```http
GET /api/affairs/teable/runtime/tables
```

返回：

```ts
{
  tables: Array<{
    tableId: string;
    tableName: string;
  }>;
}
```

### 2. 读取视图列表

```http
GET /api/affairs/teable/runtime/tables/:tableId/views
```

返回：

```ts
{
  views: Array<{
    viewId: string;
    viewName: string;
    viewType: "grid" | "calendar" | "kanban" | "form" | "gallery" | "plugin";
    options: Record<string, unknown>;
    columnMeta?: unknown;
    filter?: unknown;
    orderBy?: unknown;
    group?: unknown;
  }>;
}
```

### 3. 读取字段列表

```http
GET /api/affairs/teable/runtime/tables/:tableId/fields?viewId=...
```

返回：

```ts
{
  fields: Array<{
    fieldId: string;
    fieldName: string;
    fieldType: string;
    isPrimary: boolean;
    isComputed: boolean;
    isLookup: boolean;
    isMultipleCellValue: boolean;
    recordRead: boolean;
    recordCreate: boolean;
    options: Record<string, unknown>;
  }>;
}
```

## 4. 读取记录

```http
GET /api/affairs/teable/runtime/tables/:tableId/records?viewId=...&take=100&skip=0&search=...
```

返回：

```ts
{
  records: Array<{
    recordId: string;
    fields: Record<string, unknown>;
  }>;
  total?: number;
  skip: number;
  take: number;
}
```

## 5. 新建记录

```http
POST /api/affairs/teable/runtime/tables/:tableId/records
```

请求：

```ts
{
  fields: Record<string, unknown>;
}
```

## 6. 更新记录

```http
PATCH /api/affairs/teable/runtime/tables/:tableId/records/:recordId
```

请求：

```ts
{
  fields: Record<string, unknown>;
  order?: {
    viewId: string;
    anchorId: string;
    position: "before" | "after";
  };
}
```

说明：实现前需要联调确认当前 Teable 版本是支持单条 `PATCH /record/{recordId}`，还是继续使用仓库里已有的批量 `PATCH /record`。

## 7. 删除记录

```http
DELETE /api/affairs/teable/runtime/tables/:tableId/records?recordIds=rec1&recordIds=rec2
```

## 错误码建议

- `TEABLE_BINDING_REQUIRED`：没有 Teable 连接
- `TEABLE_AUTH_REQUIRED`：没有可用 token
- `TEABLE_TABLE_NOT_FOUND`：表不存在
- `TEABLE_VIEW_NOT_FOUND`：视图不存在
- `TEABLE_FIELD_NOT_WRITABLE`：字段不可写
- `TEABLE_RECORD_NOT_FOUND`：记录不存在
- `TEABLE_API_REQUEST_FAILED`：Teable API 调用失败


## 8. 读取关联字段候选记录

```http
GET /api/affairs/teable/runtime/tables/:tableId/fields/:fieldId/link-options?search=...&take=50&skip=0
```

说明：

- `tableId` 是当前表。
- `fieldId` 是当前表里的关联字段。
- Host 根据字段配置找到关联表。
- 候选记录优先显示关联表主字段。
- 这个接口只用于选择已有关联记录，不用于修改 Teable 字段结构。

返回：

```ts
{
  options: Array<{
    recordId: string;
    title: string;
    subtitle?: string;
  }>;
  skip: number;
  take: number;
  hasMore: boolean;
}
```

## 9. 计算字段刷新规则

公式、查找、条件查找、汇总、条件汇总字段不提供写接口。

创建或更新记录成功后，前端需要重新调用记录读取接口。Host 不在本地计算这些字段，只返回 Teable API 的最新结果。
