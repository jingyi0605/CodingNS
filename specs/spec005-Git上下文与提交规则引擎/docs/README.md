# 补充文档目录 - spec005

`docs/` 用来存放 `spec005-Git上下文与提交规则引擎` 的补充材料和验收证据。

推荐放这些文件：

- `api.md`：Git 接口清单、请求示例、错误码说明
- `integration.md`：前后端联调步骤和联调问题记录
- `rule-examples.md`：提交规则配置样例与违规样例
- `acceptance-checklist.md`：验收清单
- `acceptance-result.md`：验收结果与问题复盘

使用约束：

- 文档必须写人话，别堆术语
- 每条联调问题都要有“现象、原因、结论”
- 每次规则调整都要记录“改了什么、为什么改”
- 验收结果必须能追溯到 `tasks.md` 中对应任务
