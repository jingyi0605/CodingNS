# spec005-Git上下文与提交规则引擎

## 当前定位

这个 Spec 负责把 Git 从“能点几个按钮”提升到“能约束实际提交流程”的可用能力。

## 计划覆盖

- Git 状态、diff、暂存、提交、分支、历史
- 提交信息规则模板
- 提交前校验与规则引擎
- 项目级提交规范接入
- AI 生成提交信息后的二次校验

## 依赖关系

- 前置依赖：`spec001`、`spec003`
- 后续依赖：移动端轻量提交流程

## 本阶段明确不做

- 企业级审计流
- 多人代码评审系统
- 云端托管 Git 平台替代品
