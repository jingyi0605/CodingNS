# 20260602-标签系统重写验收说明

这份说明只验收当前这版标签系统。

## 1. 先看这次到底要验什么

这次只验五件事：

1. 文件详情能直接搜索标签、创建标签、分配标签
2. 文件夹详情也能走同一套逻辑
3. 右键文件 / 文件夹也能走同一套逻辑
4. 文件夹绑定对后续新增文件仍然生效
5. 智能标签能配置规则、能命中、能解释

## 2. 核心场景

### 场景 A：文件详情快捷打标签

1. 打开事务文档库，选中一个文件
2. 在右侧标签输入框输入已有标签关键字
3. 看到匹配结果，点选后完成分配
4. 再输入一个不存在的标签名
5. 直接创建并分配

预期结果：

- 不需要先打开标签管理模态框
- 新标签创建后立刻出现在当前文件标签结果里

### 场景 B：文件夹详情快捷绑定标签

1. 选中一个文件夹
2. 在文件夹标签区输入已有标签关键字
3. 完成绑定
4. 再输入一个不存在的标签名
5. 直接创建并绑定

预期结果：

- 文件夹详情和文件详情用的是同一套交互思路
- 绑定结果保存后可立即回读

### 场景 C：右键入口快速分配标签

1. 右键一个文件
2. 打开标签分配入口
3. 搜索已有标签并分配
4. 再右键一个文件夹
5. 搜索或新建标签并分配

预期结果：

- 右键菜单不再只是固定几个标签按钮
- 文件和文件夹入口行为一致

### 场景 D：文件夹绑定覆盖未来新文件

1. 给某个文件夹绑定标签
2. 在该文件夹或其子文件夹下新增一个文件
3. 等待索引 / 刷新完成
4. 打开新文件详情

预期结果：

- 新文件自动出现该文件夹继承标签
- 不需要再手动补点一次

### 场景 E：智能标签规则命中

1. 打开标签管理模态框
2. 创建一个智能标签
3. 添加规则，例如：
   - 文件名包含 `合同`
   - 文件类型为 `.docx`
4. 保存后触发重算
5. 打开命中文件详情

预期结果：

- 文件出现该智能标签
- 能看到来源是智能规则
- 能看到命中证据

## 3. 回归重点

### 3.1 不要回归成三套入口三套逻辑

检查点：

- 文件详情
- 文件夹详情
- 右键菜单

这三个入口都必须能：

- 搜索
- 新建
- 分配

### 3.2 不要回归成“当前文件有效，未来文件失效”

检查点：

- 文件夹绑定后新增文件
- 智能规则保存后新增文件

都要自动补标签结果。

### 3.3 不要把系统派生标签混进手动候选

检查点：

- `类型/*`
- `时间/*`

仍然只做展示和筛选，不应该混进手动可选标签列表。
