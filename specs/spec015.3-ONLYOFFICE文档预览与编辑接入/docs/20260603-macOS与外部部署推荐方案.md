# 20260603-macOS与外部部署推荐方案

这份文档只回答一个问题：

如果你要在 `CodingNS` 里启用 ONLYOFFICE，macOS 和 Windows 上到底怎么配最省事。

## 1. 推荐顺序

### macOS

优先顺序：

1. **Docker / Docker 兼容运行环境里跑 ONLYOFFICE**
2. 本机不想跑容器，就填一台外部 Linux / Windows 的 ONLYOFFICE 地址
3. 不建议把“本机虚拟机再装 ONLYOFFICE”当默认方案，太重

### Windows

优先顺序：

1. **同机直接部署 ONLYOFFICE**
2. 或者填一台外部 ONLYOFFICE 服务

## 2. 设置页里这几个字段怎么填

### ONLYOFFICE 服务地址

这是 `CodingNS` 前端加载 `api.js` 和 ONLYOFFICE 自己渲染编辑器用的地址。

例子：

- `http://127.0.0.1:8088`
- `http://192.168.1.50:8088`
- `https://onlyoffice.example.com`

### CodingNS 对外地址

这是 **ONLYOFFICE 服务回头访问 CodingNS** 时要用的地址。

它至少会被拿去生成：

- 文件下载 URL
- 默认回调 URL

例子：

- 本机容器同机部署：`http://host.docker.internal:3002`
- 局域网机器：`http://192.168.1.20:3002`
- 反向代理公网地址：`https://codingns.example.com`

别乱填 `localhost`。如果 ONLYOFFICE 不在同一网络命名空间里，它根本打不回来。

### 回调地址

这是给 ONLYOFFICE 保存后回调用的基地址。

- 为空时，系统默认用“CodingNS 对外地址”
- 只有你明确知道回调要走另一条外网入口时，才单独填它

## 3. 三种常见部署法

### 方案 A：macOS + Docker 同机部署

- ONLYOFFICE 服务地址：容器暴露出来的地址，比如 `http://127.0.0.1:8088`
- CodingNS 对外地址：建议填 `http://host.docker.internal:3002` 或你自己映射出来的局域网地址
- 回调地址：通常留空，走上面的对外地址

适合：

- 单机使用
- 本地内测
- 不想再开第二台机器

### 方案 B：Windows 同机部署

- ONLYOFFICE 服务地址：本机实际监听地址，比如 `http://127.0.0.1:8088`
- CodingNS 对外地址：如果两者同机且可互访，可以填本机地址；如果还有代理层，填代理层外部地址
- 回调地址：通常留空

适合：

- 私有部署单机方案
- 用户并发不高的小团队

### 方案 C：外部 ONLYOFFICE 服务

- ONLYOFFICE 服务地址：外部服务的正式地址，比如 `https://onlyoffice.example.com`
- CodingNS 对外地址：必须填 ONLYOFFICE 真能访问到的地址，不能填 `localhost`
- 回调地址：如果保存流量和文件流量走同一入口，就留空；否则单独填

适合：

- 多台机器分开部署
- 需要更稳定的服务隔离

## 4. 最容易填错的地方

### 错误 1：ONLYOFFICE 是外部地址，但回调还填 localhost

表现：

- 文档能打开
- 保存没反应，或者 ONLYOFFICE 提示保存失败

原因：

- 外部 ONLYOFFICE 根本访问不到你的 `localhost`

### 错误 2：只填了回调地址，没填 CodingNS 对外地址

表现：

- 回调可能能通
- 但 ONLYOFFICE 拉不到原始文件

原因：

- 文档 URL 和回调 URL 都需要一条可访问的 CodingNS 地址

### 错误 3：ONLYOFFICE 开了 JWT，但 CodingNS 没填密钥

表现：

- 编辑器直接打不开
- 或 ONLYOFFICE 返回未授权

原因：

- 双方没用同一份密钥签名配置

## 5. 这次实现里没替你做什么

- 不自动部署 Docker
- 不自动改反向代理
- 不自动探测公网可达性

系统能帮你做的是：

- 检查 ONLYOFFICE 服务本身是不是活着
- 检查 `api.js` 能不能访问
- 检查你填的地址是不是绝对 URL
- 在明显不合理时给出警告

公网、容器网络、反向代理这类问题，还是得按你的部署环境自己配。
