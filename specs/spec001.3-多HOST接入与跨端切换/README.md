# spec001.3-多HOST接入与跨端切换

## 当前定位

这是 `spec001` 下的新子 Spec。

它只解决一件事：把当前“单 host 地址输入框”升级成正式的多 HOST 机制，并且让桌面端、移动端都能方便切换。

这次不接受糊弄方案。

真正要定住的是：

- HOST 在前端里到底是什么数据结构
- 当前激活 HOST 怎么切
- 不同 HOST 的登录态怎么隔离保存
- 桌面端和移动端入口怎么接，才能切得快、看得懂、不把现有工作区导航搞乱
- 桌面端本机已经运行中的 `codingns` Host 如何自动发现、归类展示和与手工 HOST 去重，这部分由 `spec001.3.1-桌面端本机HOST自动发现` 继续展开

## 计划覆盖

- 多 HOST 的前端配置模型
- HOST Profile 的本地持久化和桌面壳持久化
- 按 HOST 隔离的登录态、记住密码和最近连接信息
- HOST 切换时 HTTP / WebSocket / 页面运行时的统一收口
- 桌面端顶部 HOST 切换器接入
- 移动端顶部工作区切换器改成 `HOST -> 工作区` 树

## 依赖关系

## 本阶段明确不做

- 同时连接多个 HOST 并把多个 HOST 的会话、终端、文件树并排混在一个主舞台里
- 把 HOST 配置同步到服务器数据库
- 改写 Host 后端认证协议本身
- H5 场景下的复杂多 HOST 管理体验
