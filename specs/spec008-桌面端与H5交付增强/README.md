# spec008-桌面端与H5交付增强

## 当前定位

这个 Spec 负责桌面壳和 H5 的交付体验，但不碰核心业务真相。

`spec008` 只处理“大交付问题”，不要继续把桌面端工作台多窗口塞回这里。
桌面端多窗口已经拆到子 Spec：`spec008.1-桌面端多窗口管理`。

## 计划覆盖

- Tauri 桌面壳接入
- H5 访问体验
- 连接建立与恢复体验
- 桌面分发、升级、配置
- 桌面端与 Web 共享 UI 的边界

## 依赖关系

- 前置依赖：`spec001`、`spec003`
- 后续依赖：`spec009`

## 本阶段明确不做

- 把业务逻辑塞进 Tauri 壳层
- 平台专属功能泛滥
- 与移动端完全不同的一套交互体系
- 桌面端工作台多窗口细节设计和实现（转交 `spec008.1`）
