# spec001.11 - 多用户数据隔离与用户管理基础

## 这份 Spec 要解决什么

当前项目已经有登录、Token、设备管理和部分 `user_id` 字段，但核心数据还没有真正按用户隔开。

现在的问题不是“能不能登录第二个人”，而是：

- 第二个人登录后会不会看到第一个人的工作区
- 会话、Butler、后台运行态会不会串到一起
- 后端是不是还偷偷拿“第一个用户”当默认用户

这份 Spec 就是先把这些最基础的问题收住。

## 这份 Spec 的范围

本期只做“多用户基础隔离”，不做团队协作大平台。

本期重点：

1. 建立正式的用户管理入口
2. 给工作区和核心会话数据补用户归属
3. 把 Butler 从全局默认对象改成按用户独立
4. 清理代码里“默认第一个用户”的单用户假设
5. 给关键 API 和后台任务补用户作用域校验

本期明确不做：

- 工作区多人协作权限模型
- 复杂组织、团队、租户系统
- 历史所有边角表一次性全量改完
