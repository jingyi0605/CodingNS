# spec004.1-文件预览内核与模态工具增强

## 当前定位

`spec004` 已经把文件树、基础预览和基础编辑搭起来了，但文件预览这块还很瘦：

- HTML 走了单独预览链路
- Markdown 只能算半个预览
- 图片和 PDF 这类高频格式还没有正式内置预览
- 预览模态框尺寸固定，内容一大就难用
- 工具按钮基本一刀切，看什么文件都差不多

这次不重做文件管理，也不碰 Office。

一句人话：

这一步就是把“能看”这件事先做好，让文件预览别再停留在文本框加 iframe 拼凑阶段。

## 计划覆盖

- `TXT / Markdown / 代码文本` 继续走内置预览和基础编辑
- `图片` 增加正式内置预览
- `PDF` 增加正式内置预览
- 文件预览模态框支持调整大小，并保留合理默认尺寸
- 不同文件格式展示不同工具按钮
- 为后续 `Office / 插件化预览` 预留统一扩展接口

## 依赖关系

- 前置依赖：`spec004`、`spec003`
- 主要影响：`apps/host/src/modules/file/`、`apps/user-app/src/features/conversation/components/FileViewerModal.tsx`
- 后续可承接：`Office` 文件预览、预览插件体系、更多格式工具栏扩展

## 本阶段明确不做

- 不把 `TXT / PDF / 图片` 交给外部 H5 在线工具作为主方案
- 不引入 Office 文档预览实现
- 不把文件预览升级成重型 IDE
- 不为了 PDF 去启动独立开发服务器或单独长一套页面系统
