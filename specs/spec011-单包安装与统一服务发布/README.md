# spec011-单包安装与统一服务发布

## 当前定位

这个 Spec 负责把当前项目收敛成一个正常可交付的服务包，而不是继续维持“前端一个命令、后端一个命令、谁部署谁自己拼”的开发态结构。

目标很直接：

- 用户执行一条 `npm` / `npx` 命令就能拿到完整服务
- 前端构建产物由后端统一托管，不再要求额外跑 Vite
- 服务启动时可以显式设置端口、主机和数据目录
- 服务可以交给 `pm2` 这类进程管理器长期托管

## 计划覆盖

- 新增可发布的 `@jingyi0605/codingns` 服务包
- 增加统一 CLI 入口 `codingns start --port`
- 增加 `build:standalone` 构建链路
- 后端托管前端静态资源和 SPA 路由
- 补齐 PM2 启动与托管说明

## 依赖关系

- 前置依赖：`spec001`、`spec007`、`spec008`
- 后续依赖：桌面端安装器分发、Docker 交付、systemd 示例

## 本阶段明确不做

- 不做桌面端安装包改造
- 不做 Docker 镜像流水线
- 不做自动后台安装后自启动
- 不做分布式部署和多实例编排
