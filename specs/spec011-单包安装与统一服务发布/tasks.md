# 任务清单 - spec011-单包安装与统一服务发布（人话版）

状态：DONE

## 这份文档是干什么的

这份任务清单是为了把“项目能跑”变成“项目能发布、能安装、能托管”。

它要回答的是：

- 先把哪一块变成正式服务包
- 前端静态资源怎么并进后端
- CLI 怎么定义才适合上线跑
- 构建链路怎么收敛成一个命令
- PM2 文档怎么写到别人能直接抄

---

## 状态说明

- `TODO`：还没开始
- `IN_PROGRESS`：正在做
- `BLOCKED`：被外部问题卡住
- `IN_REVIEW`：已经有结果，等待复核
- `DONE`：已经完成，并且已经回写状态
- `CANCELLED`：取消，不做了，但要写原因

规则：

- 只有 `状态：DONE` 的任务才能勾选成 `[x]`
- 每完成一个任务，必须立刻更新本文件状态
- `BLOCKED` 和 `CANCELLED` 必须写清楚原因
