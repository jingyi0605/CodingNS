# spec007-进程管理与启动器

## 当前定位

这个 Spec 负责把“运行项目”做成真正的一等能力，而不是几个零散命令按钮。

## 计划覆盖

- `LauncherProfile` 模型
- 进程发现、启动、停止、重启
- 日志查看
- 端口识别
- 常见项目启动模板
- 进程与工作区、终端的关系

## 依赖关系

- 前置依赖：`spec001`、`spec006`
- 后续依赖：移动端查看与通知

## 本阶段明确不做

- 分布式调度
- 容器编排
- 企业级运维平台能力
