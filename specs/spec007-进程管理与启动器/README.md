# spec007-进程管理与启动器

## 当前定位

这个 Spec 负责把“运行项目”做成真正的一等能力，而不是几个零散命令按钮。

它解决的是底座问题：

- 启动配置怎么建模
- 进程怎么启动、停止、重启
- 日志和端口怎么被统一管理

但它还不解决另一个更上层的问题：

- 外部 Git 仓库里往往不止一个服务
- 不同工作树并行调试时会撞默认端口
- 平台该先用参数、环境变量还是临时覆盖文件去解冲突

这部分由 `spec007.1-外部仓库调试进程端口编排与启动适配` 承接。

## 计划覆盖

- `LauncherProfile` 模型
- 进程发现、启动、停止、重启
- 日志查看
- 端口识别
- 常见项目启动模板
- 进程与工作区、终端的关系

## 依赖关系

- 前置依赖：`spec001`、`spec006`
- 后续依赖：
  - `spec007.1-外部仓库调试进程端口编排与启动适配`
  - 移动端查看与通知

## 本阶段明确不做

- 分布式调度
- 容器编排
- 企业级运维平台能力
