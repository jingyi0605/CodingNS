# spec009-移动端体验与通知

## 当前定位

这个 Spec 负责移动端“查看 + 轻操作 + 通知”体验，不做伪装成桌面 IDE 的垃圾方案。

## 计划覆盖

- 移动端信息架构
- 会话查看与回复
- 文件 / Git / 进程轻操作
- 全屏终端与日志查看边界
- 推送通知与提醒策略

## 依赖关系

- 前置依赖：`spec003`、`spec004`、`spec005`、`spec007`、`spec008`
- 后续依赖：无

## 本阶段明确不做

- 移动端重型开发体验
- 复杂多任务编辑
- 假装手机上能替代桌面主力工作流
