# spec006-终端核心能力

## 当前定位

这个 Spec 负责 PTY、终端实例和连接恢复，不把终端和进程胡乱搅在一起。

## 计划覆盖

- PTY 生命周期管理
- 终端实例模型
- 多终端基础能力
- 终端断线重连
- 终端输出缓存
- 工作区绑定与命令模板

## 依赖关系

- 前置依赖：`spec001`
- 后续依赖：`spec007`

## 本阶段明确不做

- 把进程管理硬塞进终端模型
- 浏览器端假终端
- 花哨但无用的终端装饰能力
