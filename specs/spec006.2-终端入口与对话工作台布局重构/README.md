# spec006.2-终端入口与对话工作台布局重构

## 当前定位

这个子 Spec 只解决一件事：

- 把“终端是一个独立页面入口”的旧做法，改成“终端是代码视图里的常驻工作面板”

一句人话：
用户不是想多点一次路由跳转，他是想在聊天和终端之间顺手切换，还能保留上次自己调好的位置和大小。

## 计划覆盖

- 把终端入口从左上角菜单迁到左侧边栏底部“快捷应用”
- 在代码视图里补出和事务视图一致的快捷应用区
- 把终端页主显示改成对话区里的抽屉式终端面板
- 支持上下 / 左右两种布局和中间拖拽调比例
- 让终端面板的开关状态、布局方向、比例在工作区内持久化恢复
- 保持现有终端后端、终端实例、终端实时链路不变

## 依赖关系

- 前置依赖：`spec006`、`spec006.1`、`spec016`
- 直接影响：`apps/user-app`
- 重点改动区：`WorkbenchLayout`、`AffairsWorkbenchView`、`TerminalManagerPanel`、终端相关前端状态与样式

## 本阶段明确不做

- 不改终端创建、关闭、输入输出、日志持久化这些后端逻辑
- 不新做一套终端 runtime 协议
- 不把事务视图现有快捷应用存储直接改成后端持久化
- 不在这一轮顺手重做移动端终端页面
- 不处理终端多人协作、共享会话、权限模型扩展
