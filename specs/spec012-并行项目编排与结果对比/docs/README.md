# 补充文档目录

`docs/` 用于存放 `spec012-并行会话组与临时子工作区` 的补充材料。

这份 Spec 后续更可能补这些东西：

- `api.md`
  - 并行组创建、成员删除、临时工作区升级等接口说明
- `state-machine.md`
  - 并行组、成员和临时工作区的状态流转
- `ui-notes.md`
  - 创建弹窗、分屏布局、悬浮信息栏和会话树标识说明
- `acceptance-checklist.md`
  - 两种创建路径、临时工作区升级、删除清理和零破坏回归的验收清单
- `migration.md`
  - 从“手工多次 fork + 手工建子工作区”迁移到系统托管并行会话的说明
- `risk-log.md`
  - 记录锚点漂移、临时资源残留、展示关系错乱、误删正式子工作区等风险

如果当前阶段还没有补充材料，先保留本文件。
