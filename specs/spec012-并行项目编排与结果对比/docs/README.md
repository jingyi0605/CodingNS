# 补充文档目录

`docs/` 用于存放 `spec012-并行项目编排与结果对比` 的补充材料。

这个 Spec 后续大概率会补这些东西：

- `api.md`
  - 并行案例、尝试、结果对比、清理等接口说明
- `integration.md`
  - 和 `spec005`、`spec007`、`spec010` 的集成说明
- `acceptance-checklist.md`
  - worktree、端口隔离、结果采集、清理回收的验收清单
- `migration.md`
  - 从“手工多目录并行”迁移到系统托管并行案例的说明
- `risk-log.md`
  - 记录端口冲突、目录残留、误删、merge 误判等风险

如果当前阶段还没有补充材料，先保留本文件。
