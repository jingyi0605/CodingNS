# spec001 补充文档目录说明

这个目录用来放 `spec001` 的补充材料，不和主文档混在一起。

主文档在上一级目录：

- `requirements.md`
- `design.md`
- `tasks.md`

建议在本目录补充以下材料：

1. `API清单.md`
   - 公开接口与受保护接口的最终清单
   - 请求示例与错误码示例
2. `鉴权联调清单.md`
   - 初始化、登录、刷新、登出的联调步骤
   - WebSocket 握手鉴权联调步骤
3. `存储边界检查清单.md`
   - SQLite 表字段检查结果
   - 原始会话消息不入库检查结果
4. `验收记录.md`
   - 每条需求对应的验证证据
   - 阻塞问题与解决记录

维护要求：

- 文档更新要和 `tasks.md` 的任务状态同步
- 每次关键评审后，补一条结论记录
- 不写空话，重点写“结论是什么、证据是什么、下一步是什么”
