# spec009.3 移动端首页代码事务与文档库体验重构

状态：Draft

## 这是什么

这份 Spec 规划移动端下一轮真正该改的页面结构：

- 底部导航改成 `首页 / 对话 / 代码 / 文档 / 工作台`
- `我的` 不再占底部入口，移到首页顶部头像
- 首页同时汇总代码模式和事务模式的信息
- 代码模式保留工作区切换器
- 文档页按当前 PC 端文档库真实结构重做移动端体验

## 为什么要做

当前移动端还带着旧版“助手会话 + 终端入口”的影子，和 PC 端现在的产品结构不一致。

PC 端现在已经分成：

- 代码视图
- 事务视图：文档库、对话、工作台

移动端不能继续把旧入口简单缩小。手机上要优先解决：

1. 一打开就知道今天要处理什么
2. 快速进入轻量事务对话
3. 快速定位代码工作区并继续代码会话
4. 能像 PC 文档库一样按目录、收藏、标签和对象详情处理文档
