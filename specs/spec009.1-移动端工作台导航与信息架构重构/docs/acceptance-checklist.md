# 验收清单

这份清单不是摆设，后面每次实现阶段都要对着它过。

## 1. 基础结构

- [ ] 已登录后不再只有单一 `WorkbenchLayout` 一个壳
- [ ] `compact / medium / expanded` 三档宽度等级已建立
- [ ] `desktop / web / ios / android` 运行时识别已建立
- [ ] 移动端一级目的地固定为 `工作区 / 会话 / 工具 / 设置`

## 2. 移动端主路径

- [ ] 手机竖屏进入后，不再依赖左抽屉作为一级导航
- [ ] 手机竖屏进入后，不再依赖右抽屉承载文件 / Git / 终端主入口
- [ ] 左右边缘手柄已退出移动端主路径
- [ ] 用户不需要理解桌面三栏，也能进入主功能

## 3. 页面层级

- [ ] 工作区首页可以进入工作区详情
- [ ] 会话索引页可以进入会话详情
- [ ] 会话详情页保持消息流和输入区为主
- [ ] 工具首页可以进入文件 / Git / 终端 / 进程 / 日志
- [ ] 设置页独立存在，不再挂靠在桌面壳尾部按钮语义

## 4. 动作呈现

- [ ] 新建会话保留一级直达
- [ ] 搜索有明确入口
- [ ] 导入工作区和克隆工作区已迁到更多菜单或 sheet
- [ ] 批量选择会话已迁到编辑模式
- [ ] 会话重命名、收藏、归档已迁到长按 / 菜单 / 滑动动作
- [ ] 手机标题栏没有并排 3 个以上小图标

## 5. 工具流

- [ ] 文件不再作为手机右侧栏 tab 常驻
- [ ] Git 不再作为手机右侧栏 tab 常驻
- [ ] 终端管理不再作为手机右侧栏 tab 常驻
- [ ] 工具进入重操作后可以升级为全屏页

## 6. 平台差异

### H5 移动端

- [ ] 底部导航、安全区、动态视口高度处理正确
- [ ] 键盘弹出时输入区和底部导航不冲突
- [ ] 不依赖浏览器返回作为唯一返回路径

### iOS

- [ ] 主导航符合 Tab Bar + Navigation Stack 模型
- [ ] 返回手势正常
- [ ] 次操作以 menu / sheet / action sheet 为主

### Android

- [ ] 主导航符合 Bottom Navigation + Top App Bar 模型
- [ ] 系统返回和页面状态一致
- [ ] 次操作以 overflow menu / bottom sheet 为主

## 7. 宽度等级

- [ ] `compact` 为单栏堆栈式
- [ ] `medium` 支持列表 + 详情或主内容 + 辅助区
- [ ] `expanded` 可回到双栏或三栏，但不破坏移动端导航意图
- [ ] 旋转和宽度变化不丢上下文

## 8. 桌面回归

- [ ] 桌面端三栏工作台主路径保持可用
- [ ] 桌面端工作区、会话、文件、Git、终端主流程不回归
- [ ] 移动端改造没有把桌面入口顺手改坏

## 9. 通过标准

只有当下面 3 条同时成立，才算这个子 Spec 真正通过：

1. 手机主路径已经不再是桌面抽屉版
2. 功能没有因为移动端改造而缩水
3. 桌面端没有被一并拖下水
