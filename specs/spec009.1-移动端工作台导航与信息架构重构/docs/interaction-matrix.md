# 交互迁移矩阵

这份文档只做一件事：

- 把当前 `WorkbenchLayout` 里的真实入口、按钮、tab、菜单动作盘清楚
- 给每个动作一个移动端去向

不这样做，后面一定会漏动作，最后又回到“先塞个抽屉顶着”的垃圾方案。

## 1. 当前入口总览

当前工作台入口主要来自 4 块：

1. 左侧导航头部
2. 左侧导航主体
3. 工作区卡片与会话卡片
4. 右侧信息栏

对应主要代码位置：

- `apps/user-app/src/features/conversation/components/WorkbenchLayout.tsx`

### 1.1 左侧导航头部

| 当前入口 | 代码位置 | 当前问题 |
| --- | --- | --- |
| 隐藏左侧栏 | `WorkbenchLayout.tsx` 左侧栏头部 | 手机上没有意义，属于桌面折叠动作 |
| 返回 | 左侧栏头部 | 手机上不该放在侧栏里 |
| 前进 | 左侧栏头部 | 手机上不应该常驻占位 |

## 2. 动作分级

后续所有动作先分级，再决定放哪。

| 等级 | 判断标准 | 例子 |
| --- | --- | --- |
| 主操作 | 高频、主流程离不开 | 新建会话、发送消息、切换一级目的地 |
| 常用操作 | 经常使用，但不必常驻大按钮 | 搜索、切换工具 tab、收藏 |
| 次操作 | 低频、不值得常驻 | 重命名、克隆、导入 |
| 风险操作 | 误触成本高 | 归档、批量归档、提交、破坏性操作 |

## 3. 迁移矩阵

### 3.1 一级导航迁移

| 当前入口 | 移动端去向 | H5 | iOS | Android |
| --- | --- | --- | --- | --- |
| 会话 | 一级导航 `会话` | 底部导航 | Tab Bar | Bottom Navigation |
| 终端 | 并入 `工具` 一级导航 | 工具页二级入口 | 工具页二级入口 | 工具页二级入口 |
| 搜索 | 顶部搜索入口 / 独立搜索页 | 顶部按钮 | Navigation Bar 按钮 | Top App Bar 按钮 |
| 设置 | 一级导航 `设置` | 底部导航 | Tab Bar | Bottom Navigation |

说明：

- 当前左侧 segment 里的 `终端` 不能继续作为和 `会话` 并排的一级入口。
- 文件、Git、终端、进程、日志这些能力，在手机上要收敛成 `工具` 这个一级目的地。

### 3.2 工作区相关动作迁移

| 当前动作 | 移动端去向 | 呈现方式 |
| --- | --- | --- |
| 导入工作区 | 工作区首页右上更多菜单 | menu / bottom sheet |
| 克隆工作区 | 工作区首页右上更多菜单 | menu / bottom sheet |
| 切换工作区 | 工作区首页卡片点击；详情页里切换当前工作区 | 列表点击 / 菜单项 |
| 新建会话 | 工作区详情页主操作 | H5 顶部主按钮 / iOS 导航栏按钮 / Android FAB |
| 批量选择会话 | 会话索引页编辑模式入口 | 编辑模式 |
| 归档文件夹 | 工作区详情页更多菜单 | 菜单项 + 确认流 |

### 3.3 会话动作迁移

| 当前动作 | 移动端去向 | 呈现方式 |
| --- | --- | --- |
| 打开会话 | 会话索引页点击进入详情 | 列表点击 |
| 重命名 | 会话列表长按 / 更多菜单 | context menu / bottom sheet |
| 收藏 / 取消收藏 | 行尾菜单或滑动动作 | swipe / menu |
| 归档 | 行尾菜单 | menu + confirm |
| 子会话展开 | 会话详情内“关联会话”区域 | 二级列表，不默认大面积展开 |

### 3.4 工具动作迁移

| 当前动作 | 移动端去向 | 呈现方式 |
| --- | --- | --- |
| 文件 | 工具页 / 工作区详情二级 tab | tab / push |
| Git | 工具页 / 工作区详情二级 tab | tab / push |
| 终端管理 | 工具页 / 全屏终端页 | push / full screen |
| 文件重操作 | 文件详情全屏 | 全屏子页 |
| Git 重操作 | Git 详情全屏 | 全屏子页 |
| 终端重操作 | 终端全屏 | 全屏子页 |

### 3.5 应该删除的移动端桌面遗留动作

| 当前动作 | 处理方式 | 原因 |
| --- | --- | --- |
| 左右边缘手柄 | 删除移动端主路径 | 和系统手势冲突 |
| 左右侧栏折叠 | 删除移动端主路径 | 手机上没有常驻三栏 |
| 前进按钮 | 不再常驻 | 手机端价值低，且与系统模型不一致 |
| 桌面式小图标群 | 拆散 | 可发现性差、点按成本高 |

## 4. 结论

真正要迁的不是“样式”，而是“职责”：

- 左侧栏职责拆给工作区页、会话页、搜索入口
- 中间舞台继续保留为详情页主内容
- 右侧栏职责拆给工具页和全屏子页
- 小图标动作按主操作、次操作、风险操作重新分层

如果后面实现时有人又想把左栏和右栏改成两个手机抽屉，那就是在重复制造垃圾。
