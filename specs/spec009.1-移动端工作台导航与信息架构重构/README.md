# spec009.1-移动端工作台导航与信息架构重构

## 当前定位

这个子 Spec 只解决一件事：

- 把当前 PC 端三栏工作台，改造成适合 H5 移动端、iOS、Android 的移动端信息架构和导航结构

它不再接受下面这种偷懒方案：

- 左侧栏和右侧栏缩成手机抽屉就算“移动端”
- 一堆桌面小图标继续塞在手机头部
- iOS、Android、H5 全部共用一张被压扁的桌面页面

一句人话：
功能不能少，但手机上的入口、返回、工具面板、操作按钮，必须重新排，不准把桌面工作台缩小了硬塞。

## 计划覆盖

- 当前 PC 三栏工作台到移动端结构的映射
- H5 移动端、iOS、Android 三端各自的导航和页面容器
- 会话页、工作区页、工具页的移动端职责划分
- 当前桌面小图标动作到移动端按钮、菜单、sheet 的改造规则
- 紧凑宽度、中宽度、大宽度下的自适应布局
- `apps/user-app` 中移动端壳与桌面壳的拆分边界

## 依赖关系

- 前置依赖：`spec003`、`spec004`、`spec005`、`spec006`、`spec007`、`spec008`、`spec009`
- 直接影响：`apps/user-app`
- 后续受益：移动端原生壳接入、移动端业务对齐、平板与折叠屏布局

## 本阶段明确不做

- 不重写 Host 协议和核心业务真相
- 不在这个子 Spec 里展开通知、分享、生物识别、推送注册等系统能力细节
- 不把桌面端工作台顺手改成另一套信息架构
- 不把 iOS 和 Android 的差异偷懒抹平成一套假原生皮肤
