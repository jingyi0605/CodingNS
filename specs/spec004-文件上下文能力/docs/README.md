# spec004 补充文档目录

`docs/` 用于存放 `spec004-文件上下文能力` 的补充材料。

本 Spec 建议至少维护下面几类文档：

- `api.md`：文件相关接口与会话文件上下文接口说明
- `integration.md`：与 `spec003` 会话运行时的联调步骤和注意事项
- `acceptance-checklist.md`：按需求逐条验收的检查清单
- `acceptance-result.md`：每次验收结果与问题记录
- `security-cases.md`：路径越界、path traversal、未授权访问测试用例

建议补充内容重点：

- 明确哪些接口默认受保护，哪些错误码用于边界拒绝
- 记录文件上下文挂载的数据结构样例（只含元数据，不含会话原文）
- 记录大仓库下文件树和搜索的性能基线
- 记录与移动端轻操作相关的复用接口说明（给 `spec009` 用）
