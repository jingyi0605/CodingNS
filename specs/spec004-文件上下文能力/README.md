# spec004-文件上下文能力

## 当前定位

这个 Spec 负责文件树、文件操作、文件搜索和“把文件作为会话上下文”的完整能力边界。

## 计划覆盖

- 文件树浏览
- 文件读取、保存、创建、删除、重命名
- 搜索与最近打开
- 文件预览与基础编辑
- 文件与会话的上下文挂载关系

## 依赖关系

- 前置依赖：`spec001`、`spec003`
- 后续依赖：会话上下文增强、移动端文件轻操作

## 本阶段明确不做

- 重型 IDE 编辑器能力
- 复杂协同编辑
- 脱离工作区边界的文件访问
