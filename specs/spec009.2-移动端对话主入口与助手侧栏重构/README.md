# spec009.2-移动端对话主入口与助手侧栏重构

## 当前定位

这个子 Spec 只处理一件事：

- 把移动端“对话 / 终端 / 助手”三条主路径重新排顺，让对话页重新成为真正的主入口

这次不是简单换两个按钮名字。

它实际要解决的是：

- 文件、Git 现在还挂在独立工具页里，和对话上下文割裂
- 底部导航里的“工具 / 终端 / 助手”职责错位
- 助手页虽然已经存在，但没有补齐移动端应有的左右侧页和统一头部

一句人话：
用户现在得先理解一套很别扭的入口分工，才能找到文件、Git、终端和助手。这个结构本身就是错的，这次要把它改正。

## 计划覆盖

- 移动端底部一级导航里“对话 / 终端 / 助手 / 设置 / 工作区”的职责调整
- 对话页左滑呼出文件 / Git 全屏侧页
- 文件页、Git 页右滑或后退回到对话页
- 现有工具入口改成终端入口
- 现有终端入口改成助手入口
- 助手页顶部统一接入工作区切换器
- 助手页右滑打开对话列表，左滑打开右侧信息栏
- 助手页右侧信息栏内的 `信息 / 自动化 / 设置` 标签切换
- 旧工具路由到新结构的兼容与迁移

## 依赖关系

- 前置依赖：`spec009`、`spec009.1`、`spec004`、`spec005`、`spec006`、`spec013`
- 直接影响：`apps/user-app`
- 直接受影响页面：`ConversationPage`、`TerminalPage`、`MobileButlerPage`、`MobileWorkbenchShell`

## 本阶段明确不做

- 不改 Host 协议
- 不重写文件、Git、终端、助手的业务真相
- 不顺手重做桌面端工作台
- 不在这次把助手能力范围扩成新的后端需求
- 不为了追求“统一手势”去和 iOS / Android 系统返回手势硬碰硬
