# spec003.8 跨提供商会话统计

状态：Completed

本 Spec 为已存在的会话页面增加真实的累计统计。它和“当前上下文占用”是两类数据：前者描述整个会话累计发生过什么，后者只描述下一次请求会占用多少上下文窗口。

阶段 1 至 12 已完成。阶段 12 直接在同一份 `ProviderSessionStats` 上补齐模型调用归因和费用统计：只统计功能启用后创建的新会话，费用与 token 统计在同一次读取和折叠中产生，不新增独立费用计算通路。阶段 13 增加按周固定的 `models.dev` 价格快照同步，统计读取仍只读本地快照，历史会话继续使用已绑定的价格版本。
