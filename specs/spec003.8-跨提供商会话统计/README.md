# spec003.8 跨提供商会话统计

状态：Completed

本 Spec 为已存在的会话页面增加真实的累计统计。它和“当前上下文占用”是两类数据：前者描述整个会话累计发生过什么，后者只描述下一次请求会占用多少上下文窗口。

阶段 1 至 11 已完成。阶段 12 直接在同一份 `ProviderSessionStats` 上补齐模型调用归因和费用统计：只统计功能启用后创建的新会话，费用与 token 统计在同一次读取和折叠中产生，不新增独立成本服务、轮询器或平行账本。
