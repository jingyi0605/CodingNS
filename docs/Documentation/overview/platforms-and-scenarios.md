# 平台与场景

## 支持哪些客户端

当前文档面向以下使用形态：

- 桌面端：适合长时间开发、查看多面板、处理高频操作。
- 移动端：适合在外快速查看会话、处理提醒、浏览文件和继续轻量操作。
- 浏览器：适合临时接入、跨设备访问和无需安装客户端的场景。

## 典型使用场景

### 办公电脑持续开发，手机临时接续

你可以在主力电脑上保持 Host 运行，在手机上查看会话进度、批准必要操作、快速读日志或改小文件。

### 家里主机常驻，外出时远程访问

如果项目一直放在家里或办公室的常驻设备上，CodingNS 可以让你在外部网络中继续访问同一套工作区。

### 多台机器分别承担不同项目

当你有测试机、主开发机、备用机时，可以把它们作为不同 Host 管理，再从同一个客户端切换访问。

## 什么时候最适合用

- 你已经习惯用 AI 编程工具做持续协作。
- 你经常在多设备之间切换。
- 你不想把工作区管理、聊天记录、Git 和终端拆成几套界面。

## 什么时候不必强行上

如果你只在一台电脑上偶尔跑一次 AI 工具，也不需要远程访问，那先用本地工具就够了。CodingNS 更适合“项目要持续推进，而且设备会切换”的场景。
