# 产品概览

## CodingNS 想解决什么问题

很多 AI 编程工具本身已经很好用，但一旦你换设备、换网络、换到外面，只要不在原来的那台机器上，工作就会被切断。CodingNS 要解决的就是这个断点问题。

它把真正的开发环境留在 Host 上，再把工作区、会话和工具能力带到桌面端、移动端和浏览器里。这样你不需要在每台设备上重新整理上下文，也不需要把“聊天窗口”和“项目工具”分成两套世界。

## 它不是什么

CodingNS 不是单纯把终端塞进网页，也不是只会显示聊天记录的壳。它更像一个围绕 AI 会话工作的远程开发工作台。

## 你会接触到的几个核心概念

### Host

Host 是运行在你的开发机、服务器或常驻设备上的服务入口。它负责提供登录、会话同步、工作区管理、文件、Git、终端和远程访问能力。

### 工作区

工作区是日常使用的基本单位。一个工作区通常对应一个项目目录或仓库，你在里面查看文件、打开终端、管理 Git、继续会话。

### 会话

会话是你和 AI 编程工具持续协作的一条上下文。CodingNS 的价值之一，就是尽量让这条会话能在不同客户端之间续接，而不是每次都重新开始。

### 工具面板

文件、Git、终端这类能力都围绕工作区展开。它们不是独立系统，而是为了让你能在同一条工作流里继续完成修改、提交和检查。

## 适合什么样的使用方式

- 你有一台长期在线的开发机，希望手机或其他电脑随时能接着看项目。
- 你会在桌面端写代码，也会在移动端查看会话进展、处理提醒或改小文件。
- 你希望 AI 会话、Git 状态、文件和终端都跟着同一个工作区走，而不是分散在几套工具里。

## 当前公开能力重点

- 接续多种 AI 编程会话。
- 统一查看工作区、文件、Git 和终端。
- 支持多端访问和多 Host 切换。
- 在设置页管理远程访问、主题、语言、模型和更新。
