# Tunnel Service

## Who this is for

The tunnel service is a good fit when you want an outside-access path with less network setup work on your side.

## Where to manage it

Open the remote access area in settings and switch to the tunnel panel.

## Basic flow

1. enable the tunnel service;
2. sign in to the tunnel account if needed;
3. bind the current Host;
4. use the generated access address from other devices;
5. manage traffic or quota there if your plan uses it.
