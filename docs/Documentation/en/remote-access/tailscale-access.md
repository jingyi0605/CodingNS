# Tailscale Access

## Who this is for

Tailscale is a natural fit if your laptop, phone, and other devices already live in the same Tailscale network or if you prefer private network access over public entry points.

## Where to enable it

Open the remote access section in settings and switch to the Tailscale panel.

## Basic flow

1. enable Tailscale for the current Host;
2. adjust optional settings such as control server or hostname only if you actually need them;
3. bind the Host to your Tailscale account;
4. use the shown reachable address on another device.

## What “done” looks like

- the status shows that Tailscale is running;
- a reachable address is visible;
- another device can connect to the Host through that address.
