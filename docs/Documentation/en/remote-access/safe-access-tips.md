# Safety & Stability Tips

## Start with a stable Host

Remote access is only an entry path. It cannot fix a Host that is not running or a project setup that is already broken locally. Always make the local path work first.

## Account and device advice

- keep the administrator account password strong;
- avoid saving long-term sessions on untrusted public devices;
- only keep the devices you really use in the remote access path.

## Network advice

- use a stable connection when the task matters;
- keep mobile access for lighter actions when possible;
- choose one main remote path so you do not confuse yourself with too many entry points.

## A practical rule

The best remote setup is usually not the one with the most knobs. It is the one you can still recognize and trust the next time you need it quickly.
