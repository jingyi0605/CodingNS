# Docs Overview

## Who these docs are for

These docs are written for people who want to:

- understand what CodingNS is before installing it;
- get a Host and client running quickly;
- use workspaces, conversations, files, Git, terminal access, and remote access as one connected workflow.

## Recommended reading order

### Step 1: decide whether the product fits your workflow

Start with [Product Overview](/en/overview/product-overview) and [Platforms & Scenarios](/en/overview/platforms-and-scenarios).

### Step 2: get the shortest install path working

Continue with [Choose an Install Path](/en/quick-install/installation-paths) and [Install the Host Service](/en/quick-install/host-installation).

### Step 3: connect and log in

Then open [Connect a Client](/en/quick-install/client-connection) and [First Login](/en/quick-install/first-login).

### Step 4: fill in day-to-day usage details

After the first setup, read what you need:

- [Workspaces & Sessions](/en/user-guide/workspaces-and-sessions)
- [Conversation Workbench](/en/user-guide/conversation-workbench)
- [Files, Git & Terminal](/en/user-guide/files-git-and-terminal)
- [Settings & Updates](/en/user-guide/settings-and-updates)

## How these docs are written

- They stay on the normal user path.
- They only describe currently visible and usable product behavior.
- They focus on screens, actions, and next steps instead of behind-the-scenes implementation detail.
