# Product Overview

## What problem CodingNS solves

AI coding tools become much less useful once your workflow breaks across devices or networks. CodingNS is built to reduce that break. It keeps the real development environment on a Host, then lets you continue the same workspace and conversation from desktop, mobile, or browser access.

## What it is not

CodingNS is not just a web terminal and not just a chat shell around AI tools. It is closer to a remote development workbench centered on ongoing AI coding sessions.

## Core ideas you will see in the product

### Host

The Host is the service running on your development machine, server, or always-on device. It provides login, workspace management, conversation sync, files, Git, terminal access, and remote entry points.

### Workspace

A workspace is the main unit of daily work. It usually maps to one project directory or repository.

### Session

A session is the ongoing AI coding context you want to continue instead of restarting from scratch.

### Tool panels

Files, Git, terminal, and related tools stay tied to the current workspace so the workflow feels continuous.

## Who it fits best

- Developers who already rely on AI coding tools as part of daily work
- People who move between devices
- People who want the same project context available outside the original machine
