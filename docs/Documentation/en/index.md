## Where to start

- New to CodingNS: open [Project Overview](/en/overview/docs-overview)
- Ready to try it: open [Quick Install](/en/quick-install/installation-paths)
- Already connected to a Host: open the [User Guide](/en/user-guide/workspaces-and-sessions)
- Want to keep working outside your local network: open [Remote Access](/en/remote-access/remote-access-overview)
- Need links, groups, or support: open [Community](/en/community/community-overview)

## What CodingNS is

CodingNS is a remote AI coding workbench built around a persistent Host, real project workspaces, ongoing AI conversations, and integrated tools such as files, Git, and terminal access.

## What these docs cover

- `Project Overview`: understand the product, core ideas, and supported usage scenarios.
- `Quick Install`: get a Host running, connect a client, and finish the first login.
- `User Guide`: learn how workspaces, conversations, files, Git, terminal, and settings fit together.
- `Remote Access`: choose between Tailscale and tunnel access.
- `Community`: find official links, support entry points, and feedback guidance.
