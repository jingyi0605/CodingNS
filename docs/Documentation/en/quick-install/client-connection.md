# Connect a Client

Before you tap sign in or open a client, make sure you know which Host address you are actually trying to reach.

## Start by choosing the address you will use

Clients need the Host API entry. Typical cases:

- local trial: `http://127.0.0.1:3002`
- same local network: the LAN address of the Host machine
- outside access: the remote address you configured for that Host

## Desktop is usually the easiest first connection

Open the client and confirm that the current Host address is correct. If you only use one Host, you usually set it once and keep going.

## Mobile works best once the Host is already stable

Mobile works best with a Host that is already stable. For the smoothest first run, finish bootstrap on desktop first, then sign in from mobile.

## Browser access is good for temporary entry

If you already prepared a reachable public or private entry for the Host, open that address in the browser and continue from there.

## If the first connection fails, check these first

- Test the basic connection on the same machine or inside the same LAN first.
- Make sure you are entering the Host service address you actually plan to use.
- If cross-device access matters to you, prepare remote access early instead of waiting until the first time you really need it.
