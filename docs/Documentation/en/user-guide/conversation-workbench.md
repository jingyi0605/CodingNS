# Conversation Workbench

## This is usually the main page

The conversation workbench is where most day-to-day time is spent. It is not only where you type messages, but also where you track state, add context, review permission requests, and decide what happens next.

## What you usually see here

### Message timeline

The timeline shows the actual conversation, tool output, and runtime state changes.

### Composer area

The input area is more than a text box. It helps you combine instructions, file context, and other session-related input.

### Permission requests

When some actions need your confirmation, they appear inside the session flow so you can handle them without leaving the page.

### Queued messages

If the current run is still busy, later messages can wait in order instead of interrupting the flow.

## When to continue the same session

- the task is still part of the same project goal;
- you want the existing context to stay active;
- the current line of work is still coherent.

## When to branch or start new

- you want to try a very different solution;
- you want to continue from a previous point without changing the main path;
- you do not want new work to pollute the current context.
