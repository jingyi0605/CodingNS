# Settings & Updates

The settings area collects day-to-day preferences and system-level entry points into one place. You do not need it every minute, but the first full pass saves time later.

## Start by making the interface feel like yours

This is where you usually adjust:

- language
- theme
- whether the UI follows the system appearance

## Set your defaults once instead of repeating yourself

If you want a stable default model or permission preference, keep it here instead of repeating the same choice every time.

## Host switching and connection checks also live here

When you need to switch Hosts, confirm the current connection, or revisit access-related settings, this area is the main entry.

## Remote access belongs to normal settings, not a separate admin world

Both Tailscale and tunnel access are managed from settings, not from a separate admin product.

## Updates are grouped here for the same reason

If the current client or service exposes update checks and install actions, they are also grouped here so you do not have to manage several update paths.
