# 设置与更新

设置页是日常偏好和系统入口的收口位置。你不需要每次都进去，但第一次完整过一遍，会省掉后面很多重复动作。

## 外观与语言

你可以在这里调整：

- 语言
- 主题
- 是否跟随系统外观

如果你同时在多台设备上使用，建议先把最常用的语言和主题定下来。

## 模型与默认偏好

如果你希望不同会话默认使用某类模型或默认权限策略，可以在设置页统一管理，避免每次开始时重复调整。

## Host 与连接信息

当你需要切换 Host、修改当前连接入口或确认客户端连接状态时，也会在这里找到对应设置。

## 浏览器 Profile 与任务面板

这是 `v0.8.0` 之后新增需要重点留意的一块。

如果你要用 `office.browser`：

- 可以在这里看浏览器 Profile
- 可以看浏览器任务历史和当前状态
- 可以确认桥接链路是不是可用
- 可以区分自己现在是在走无头链路，还是显式走真实浏览器桥接

换句话说，设置页已经不只是“换主题”的地方，它也开始承接真实浏览器任务的配置入口。

## 远程访问

Tailscale 和 CodingNS Connect 都从设置页进入，方便统一管理当前设备的连接方式。

## 软件更新与版本检查

如果当前客户端或服务支持更新检查、安装或版本查看，通常也会集中在设置页里。这样你不必单独维护多套升级入口。

## 使用建议

- 第一次登录后，先把外观、语言和默认偏好设好。
- 准备跨设备使用前，先把远程访问配置好。
- 准备跑浏览器任务前，先确认 Profile、任务面板和桥接状态是不是正常。
- 当你准备长期使用一台 Host 时，记得定期关注更新入口。
