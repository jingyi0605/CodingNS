# 对话工作台

## 这是你最常待的页面

对话工作台通常是 CodingNS 里停留时间最长的页面。这里不仅是发消息的地方，也是你观察会话状态、补上下文、处理权限请求和查看运行结果的主舞台。

## 页面里通常会看到什么

### 消息流

消息流会按时间顺序展示你和 AI 的对话，以及工具调用、结果反馈和运行状态变化。

### 输入区

输入区不只是一个文本框。你可以在这里组织问题、补充上下文、附加文件，再决定发出去什么。

### 权限请求

当某些操作需要你确认时，会在会话中出现对应请求。你可以在当前页面直接处理，不用跳出到别的系统。

### 排队消息

如果当前会话还在运行，后续消息会进入等待队列，避免把上下文打乱。

## 大多数时候，继续原会话更省事

- 你只是要接着处理当前任务。
- 你还希望 AI 记住上一轮上下文。
- 你改动的是同一个项目目标。

## 碰到这些情况，再新开或分叉

- 你要尝试另一种完全不同的方案。
- 你想保留当前思路，但从历史某一步另开一条分支。
- 你不希望新问题污染现有上下文。

## 让对话更顺手的几个习惯

- 问题尽量围绕当前工作区，不要一条消息塞三个无关目标。
- 重要文件直接作为上下文带进去，能减少来回解释。
- 看到权限请求时及时处理，不要让会话长时间卡住。

## 移动端使用建议

移动端适合继续短链路操作，比如查看进展、回复一句、批准请求、读文件和确认状态。长时间高密度操作，桌面端仍然更舒服。
