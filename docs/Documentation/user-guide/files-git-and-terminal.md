# 文件、Git 与终端

日常开发通常不是单纯聊天，而是“看文件、改代码、查 Git、跑命令、再回到会话”。CodingNS 把这些能力都挂在同一个工作区下，目的就是减少来回切换。

## 文件面板适合快速看、找、改

文件面板适合做这些事：

- 浏览目录结构
- 搜索文件
- 预览文本、HTML、PDF 等常见内容
- 在需要时直接编辑小范围内容

如果你只是想快速确认某段代码、配置或结果文件，文件面板通常比另开编辑器更快。

## Git 面板帮你抓住改动边界

Git 面板主要用来帮助你掌握当前工作区的改动状态。

你可以在这里：

- 查看哪些文件有变更
- 了解当前分支状态
- 处理提交与远端同步前的确认

它不是要替代你熟悉的所有 Git 工具，而是把最常用、最需要和会话联动的部分放到同一个工作流里。

## 终端页

终端页提供真实终端，而不是静态文本框。它适合：

- 运行项目命令
- 查看即时输出
- 在同一工作区里维护多个终端实例

如果你的工作流里经常需要启动服务、跑脚本、查看输出，终端页会是和对话页并列的重要入口。

## 使用建议

### 更适合终端的场景

- 你已经知道要执行什么命令
- 你主要是在看输出和状态
- 你需要快速跑一次脚本或服务

### 更适合会话的场景

- 你还在讨论方案
- 你需要 AI 根据结果继续推进
- 你要结合文件上下文解释问题

## 常见使用顺序

最常见的节奏通常是：

1. 在会话里确认任务
2. 在文件面板看代码
3. 在 Git 面板看改动范围
4. 在终端跑命令
5. 再回到会话继续下一步
