- 想找下载、群、公开入口或反馈方式：去 [社区入口](/community/community-overview)。

## CodingNS 是什么

CodingNS 是一套围绕 AI 编程会话构建的远程工作台。它把 Host 服务、工作区、对话、文件、Git、终端和远程访问组织在一起，让你可以在不同设备上继续同一个开发过程，而不是每换一台设备就重新开一个新环境。

## 快速开始

1. 先在 [安装路径选择](/quick-install/installation-paths) 里决定怎么装。
2. 按 [安装 Host 服务](/quick-install/host-installation) 把 Host 跑起来。
3. 去 [连接客户端](/quick-install/client-connection) 连上它。
4. 在 [首次登录与开始使用](/quick-install/first-login) 完成初始化。
