## 你现在应该先看哪一部分

- 第一次接触 CodingNS，请先看 [项目概述](/overview/docs-overview)。
- 已经决定要试用，直接进入 [快速安装](/quick-install/installation-paths)。
- 服务已经跑起来，想知道页面怎么用，请看 [使用手册](/user-guide/workspaces-and-sessions)。
- 想从公司外、家里或手机上继续访问同一台 Host，请看 [远程访问](/remote-access/remote-access-overview)。
- 想找群、看链接、提反馈，请看 [社区交流](/community/community-overview)。

## CodingNS 是什么

CodingNS 是一套围绕 AI 编程会话构建的远程工作台。它把 Host 服务、工作区、对话、文件、Git、终端和远程访问组织在一起，让你可以在不同设备上继续同一个开发过程，而不是每换一台设备就重新开一个新环境。

## 这套文档包含什么

- `项目概述`：帮助你快速理解产品定位、核心能力和适合的使用场景。
- `快速安装`：告诉你先装什么、先开哪个服务、客户端怎么连。
- `使用手册`：按真实操作顺序介绍工作区、会话、文件、Git、终端和设置。
- `远程访问`：介绍 Tailscale 和 CodingNS Connect 两种外部访问方式。
- `社区交流`：放官方链接、反馈入口和常用沟通渠道。

## 阅读建议

- 如果你的目标是“今天先跑起来”，只看安装、登录和第一次创建工作区这几页就够了。
- 如果你的目标是“把日常开发迁到 CodingNS”，再继续看文件、Git、终端和远程访问。
- 如果你只是想找项目入口，不需要翻仓库里的内部 Spec；官方文档会先把普通用户真正会碰到的部分讲清楚。
