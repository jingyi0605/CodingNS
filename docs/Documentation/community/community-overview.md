# 社区入口

## 这一部分放什么

这一部分主要放三类内容：

- 官方链接
- 社区交流入口
- 问题反馈与支持说明

## 什么时候该来这里

### 想看项目最新动态

先看 [官方链接](/community/official-links)。

### 想进群交流

同样先看 [官方链接](/community/official-links)，那里会放当前对外公开的社区入口。

### 想提问题或反馈建议

看 [反馈与支持](/community/feedback-and-support)。

## 建议怎么使用社区

- 想获得最快回复时，先把版本、平台和问题现象准备好。
- 想给产品提建议时，尽量描述你在什么场景下遇到阻碍。
- 如果只是想获取下载、仓库、群入口，先从官方链接页找，不要在不同地方来回搜。
