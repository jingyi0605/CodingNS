# 社区与支持

这里集中提供官方入口、社区渠道和反馈方式。

## 常用入口

- 想看下载、仓库、群和其他公开入口：去 [官方链接](/community/official-links)。
- 想进群或看看有没有对外开放的社区渠道：也先去 [官方链接](/community/official-links)。
- 想反馈问题、提建议、说明哪里不好用：去 [反馈与支持](/community/feedback-and-support)。

## 反馈建议

- 想获得最快回复时，先把版本、平台和问题现象准备好。
- 想给产品提建议时，尽量描述你在什么场景下遇到阻碍。
- 如果只是想获取下载、仓库、群入口，先从官方链接页找，不要在不同地方来回搜。
