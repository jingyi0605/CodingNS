# 反馈与支持

## 提问前先准备什么

为了让别人更快帮到你，建议至少准备这几项：

- 你使用的是哪种客户端
- 当前连接的是哪台 Host
- 问题发生在什么页面或哪一步
- 你原本想完成什么动作

## 什么样的反馈最有用

### 描述操作路径

比如“我在工作区里打开终端后，准备继续同一条会话”这种描述，比“它坏了”有用得多。

### 说明影响范围

例如“只有手机端会这样”或“换另一台 Host 就正常”，这些信息能帮助更快判断问题边界。

### 补充截图

如果界面状态一眼就能说明问题，补截图会很有效。

## 更适合反馈的问题类型

- 安装和登录过程不清楚
- 客户端连接路径不明确
- 远程访问入口不好理解
- 页面文案、结构或操作顺序让人迷惑
- 某项已有能力在真实使用里不顺手

## 一个简单原则

越具体越好。把“在哪个页面、做了什么、看到什么、原本希望看到什么”说清楚，支持效率会高很多。
