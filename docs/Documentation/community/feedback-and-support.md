# 反馈与支持

## 把这几样信息一起带上，别人更容易帮到你

为了让别人更快帮到你，建议至少准备这几项：

- 你使用的是哪种客户端
- 当前连接的是哪台 Host
- 问题发生在什么页面或哪一步
- 你原本想完成什么动作

## 这样描述，别人更容易看懂

### 先把操作路径说完整

比如“我在工作区里打开终端后，准备继续同一条会话”这种描述，比“它坏了”有用得多。

### 再把影响范围说清楚

例如“只有手机端会这样”或“换另一台 Host 就正常”，这些信息能帮助更快判断问题边界。

### 能截图时，就别只靠一句话

如果界面状态一眼就能说明问题，补截图会很有效。

## 这些问题尤其值得提出来

- 安装和登录过程不清楚
- 客户端连接路径不明确
- 远程访问入口不好理解
- 页面文案、结构或操作顺序让人迷惑
- 某项已有能力在真实使用中体验不佳

## 记住一个简单原则

越具体越好。把“在哪个页面、做了什么、看到什么、原本希望看到什么”说清楚，支持效率会高很多。
