# 连接客户端

先别急着点登录，先把你要连的 Host 地址想清楚。  
客户端连的是 Host 服务入口，不是哪张界面截图、也不是某个临时页面地址。

## 先想清楚你准备从哪儿连

客户端需要连接到 Host 的 API 入口。最常见的情况是：

- 本机体验：`http://127.0.0.1:3002`
- 同一局域网设备：使用 Host 所在机器的局域网地址
- 外部网络访问：使用你配置好的远程访问地址

## 首次连接建议优先使用桌面端

打开客户端后，先确认当前连接的 Host 地址是否正确。如果你只有一台 Host，通常填一次就够了；如果你有多台 Host，可以后续在应用里切换。

## 手机更适合接已经稳定跑着的 Host

移动端更适合连接一台已经稳定运行的 Host。第一次使用时，建议先在桌面端完成初始化，再在手机上登录同一台 Host。

## 浏览器更适合临时进入或跨设备补位

如果你已经为 Host 准备好了可访问入口，浏览器可以直接进入对应地址。是否能在外部网络访问，取决于你的远程访问方式是否配置完成。

## 连上以后，通常先看到初始化或登录

第一次连接到一台全新的 Host 时，通常会先进入初始化或登录流程。完成后，你会看到工作台入口，而不是空白页面。

## 如果一开始连不上，先检查这三件事

- 第一次上手，尽量先在同一台机器或同一局域网内测试。
- 如果浏览器能打开、客户端却还没连上，先回头确认自己填写的是 Host 服务地址。
- 打算长期跨设备使用时，尽早把远程访问方式配好，后面切换设备会省很多事。

继续看 [首次登录与开始使用](/quick-install/first-login)，确认第一次进入后该做什么。
