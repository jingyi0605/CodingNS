# 安装路径选择

## 先搞清楚你要装什么

想用 CodingNS，通常至少要有两部分：

- 一台运行 `Host` 服务的设备。
- 一个连接到 Host 的客户端。

Host 负责保管真实工作区和工具能力；客户端负责让你在不同设备上继续访问它。

## 最常见的三种组合

### 组合一：一台开发机 + 桌面客户端

这是最适合第一次上手的方式。你只需要在常用开发机上运行 Host，然后在本机或另一台电脑上连接它。

### 组合二：一台常驻机器 + 手机客户端

适合出门在外还要继续跟进项目的人。你可以把 Host 放在家里或办公室常在线的机器上，再用手机随时查看。

### 组合三：一台 Host + 浏览器访问

适合临时接入或不方便安装客户端的场景。只要网络和入口可用，就能先通过浏览器进入。

## 安装前准备

- 一台能长期放项目目录并保持在线的设备。
- Node.js 22 及以上环境，用于运行 Host。
- 稳定的网络访问方式；如果你不在同一内网，后续还需要远程访问配置。

## 推荐路径

### 只想先体验

先装 Host，再用离它最近的客户端连上去。

### 计划长期使用

建议同时准备：

- 常驻 Host。
- 主力桌面客户端。
- 至少一种外部访问方式。
