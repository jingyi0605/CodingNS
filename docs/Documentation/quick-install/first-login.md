# 首次登录与开始使用

## 第一次进入会发生什么

如果这台 Host 还是全新状态，你会先看到初始化页面，用来创建第一个管理员账号。完成后，再进入登录页使用刚才的账号登录。

## 初始化其实很短，很快就能做完

初始化时通常只需要设置：

- 用户名
- 密码
- 确认密码

建议从一开始就使用你自己能长期记住、又不容易和其他服务混淆的账号信息。

## 登录后建议先完成这三项设置

### 1. 确认语言和主题

先把界面调整为常用的语言和外观，方便后续继续操作。

### 2. 导入或创建第一个工作区

你可以导入本地已有项目目录，也可以从仓库克隆一个新工作区。工作区准备好以后，日常操作才有落点。

### 3. 打开第一条会话

进入工作区后，打开会话页，确认自己能正常继续已有会话或开始一条新会话。

## 第一次用，不要急着把所有东西都配完

第一次不要急着把所有设置都调完。先用一两个项目走完整条路径：

1. 连接 Host
2. 登录
3. 导入工作区
4. 打开会话
5. 看文件、Git、终端
6. 再决定是否配置远程访问
