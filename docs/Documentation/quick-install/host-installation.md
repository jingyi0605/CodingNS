# 安装 Host 服务

## 这一步会得到什么

做完这一步后，你会得到一台可以被客户端连接的 CodingNS Host。后续的登录、工作区、会话、文件、Git、终端和远程访问，都围绕它展开。

## 最直接的安装方式

如果你已经准备好了 Node.js 环境，可以直接通过 npm 安装独立服务包：

```bash
npm install -g @jingyi0605/codingns
codingns start --port 3002
```

如果你不想全局安装，也可以直接运行：

```bash
npx @jingyi0605/codingns start --port 3002
```

## 常用启动参数

- `--host`：指定监听地址，默认是 `0.0.0.0`
- `--port`：指定端口，默认是 `3002`
- `--data-dir`：指定数据目录，默认会放到 `~/.codingns`
- `--demo`：以演示模式启动，适合快速试用

## 什么时候适合用演示模式

如果你只是想先看一遍流程，不打算马上导入正式项目，可以用演示模式快速进入体验。等你确认产品适合自己的工作方式，再换成正式环境。

## 让 Host 长期运行

如果这台机器准备长期提供服务，建议把 Host 交给系统服务管理工具或进程守护工具托管。这样在设备重启后，它更容易自动恢复。

## 启动完成后做什么

启动完成后，不需要先去翻后台日志。普通用户下一步只要做两件事：

1. 在客户端里填写 Host 地址。
2. 完成第一次登录或初始化。
