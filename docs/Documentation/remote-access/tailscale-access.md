# Tailscale 接入

如果你的几台设备本来就在同一个 Tailscale 网络里，或者你本来就更喜欢私有网络访问，Tailscale 往往是最省心的那条路。

## 入口就在设置页里的远程访问

进入设置页里的远程访问入口，切换到 `Tailscale` 相关面板后，就可以开始配置。

## 按这个顺序配，基本不会绕弯

### 1. 启用 Tailscale

先在设置页打开 Tailscale 入口，让当前 Host 开始检查和准备相关状态。

### 2. 按需填写配置

你可以根据自己的网络情况补充控制服务器地址或主机名。大多数普通用户只需要在有明确需求时再改这些项。

### 3. 绑定账号

完成启用后，把当前 Host 绑定到你的 Tailscale 账号。

### 4. 记录可访问地址

当状态正常后，页面会显示可访问地址、域名或 Tailnet 地址。后续你在其他设备上连接 Host 时，就可以使用它们。

## 看到这些状态，就说明已经配好了

- 当前状态显示已正常运行
- 页面里能看到可访问地址
- 另一台设备可以用对应地址连上当前 Host

## 用起来更顺手的做法

- Tailscale 更适合作为你自己的设备网络，不要把它当成公开分享入口。
- 如果你换了设备名或网络环境，记得回来确认连接状态。
- 先保证 Host 本地可用，再处理 Tailscale，不要本末倒置。
