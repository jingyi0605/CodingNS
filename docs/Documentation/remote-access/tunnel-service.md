# CodingNS Connect

如果你想更快拿到一个外部可访问地址，又不想自己折腾太多网络细节，CodingNS Connect 通常会更直接。

## 入口同样在设置页里

同样是在设置页里的远程访问入口，切到 `CodingNS Connect` 面板即可。

## 配置步骤

### 1. 启用 CodingNS Connect

先打开总开关，让当前 Host 开始读取 CodingNS Connect 状态。

### 2. 登录 CodingNS Connect 账号

如果你准备长期使用这项服务，先在面板里完成账号登录。

### 3. 绑定当前 Host

登录后，把当前设备绑定成可被远程访问的 Host。

### 4. 获取访问地址

绑定完成后，页面会显示当前可用的访问地址。这个地址就是你从外部客户端进入这台 Host 的入口。

### 5. 按需管理流量或配额

如果当前使用模式涉及流量包或配额管理，也是在这里统一查看。

## 适合暂时停用的情况

- 你当前不需要从外部访问
- 你准备更换设备或解绑当前 Host
- 你只是临时开通，任务完成后想收口

## 使用建议

- 给当前 Host 起一个容易识别的名称，后面多设备管理会更清楚。
- 经常从外部访问时，记得留意剩余流量或当前状态。
- 如果你只是自己几台设备互联，先比较一下是否更适合 Tailscale。
