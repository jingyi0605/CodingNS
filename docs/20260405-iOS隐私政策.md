# CodingNS iOS App 隐私政策

**生效日期：2026年4月5日**

**最后更新日期：2026年4月5日**

欢迎使用 CodingNS（以下简称"本应用"）。本隐私政策旨在向您说明本应用如何处理您的个人信息和数据。请在使用本应用前仔细阅读本政策。

---

## 1. 基本信息

- **应用名称**：CodingNS（码不能停）
- **Bundle ID**：com.codingns.userapp
- **开发者**：CodingNS 团队
- **适用平台**：iOS 14.0 及以上

CodingNS 是一款 AI 编程工作流平台客户端应用，帮助用户通过移动设备连接自部署的服务端，进行 AI 辅助编程、会话管理、代码编辑、终端操作及 Git 版本控制等工作。

**核心理念：本应用不收集、不传输、不共享您的任何个人数据到第三方服务器。所有数据均存储在您的本地设备上，所有网络通信仅发生在您的设备与您自行部署的服务端之间。**

---

## 2. 数据收集与使用

### 2.1 本应用收集的数据

本应用仅在本地设备上存储以下必要数据，用于保障应用功能的正常运行：

| 数据类别 | 具体内容 | 存储位置 | 用途 |
|---------|---------|---------|------|
| 认证凭证 | 访问令牌（accessToken）、刷新令牌（refreshToken） | 设备本地存储（localStorage） | 用于与您的服务端保持登录状态 |
| 登录记忆 | 用户名、密码（仅在您主动勾选"记住密码"时保存） | 设备本地存储（localStorage） | 下次登录时自动填充，方便使用 |
| 服务端配置 | 您配置的服务器地址（hostBaseUrl） | 设备本地存储（localStorage） | 连接您自行部署的后端服务 |
| 偏好设置 | 语言、主题、默认权限模式、通知偏好等 | 设备本地存储（localStorage） | 保存您的个性化设置 |
| 客户端配置 | 平台标识、运行时参数 | 设备本地存储 + 应用数据目录 | 保障应用正常运行 |

**上述所有数据均存储在您的 iOS 设备本地，不会发送至 CodingNS 团队或任何第三方服务器。**

### 2.2 本应用不收集的数据

本应用明确**不收集**以下数据：

- 地理位置信息
- 设备标识符（包括 IDFA、IDFV）
- 联系人信息
- 通讯录
- 短信或通话记录
- 健康数据
- 浏览历史
- 用户行为分析数据
- 任何用于广告定向的用户画像数据
- 生物识别信息（面容 ID、指纹等）

## 3. 权限使用说明

本应用仅申请了实现核心功能所必需的最少权限：

### 3.1 相机权限（NSCameraUsageDescription）

- **用途**：用于在聊天会话中拍照，并将照片作为图片附件发送。
- **触发时机**：仅在您主动点击聊天中的拍照/附件按钮时请求。
- **数据去向**：拍摄的照片仅发送至您自行配置的服务端，不会传输至任何第三方。

### 3.2 相册读取权限（NSPhotoLibraryUsageDescription）

- **用途**：用于从您的相册中选择图片，作为聊天附件发送。
- **触发时机**：仅在您主动点击聊天中的相册/附件按钮时请求。
- **数据去向**：选择的图片仅发送至您自行配置的服务端，不会传输至任何第三方。

### 3.3 相册写入权限（NSPhotoLibraryAddUsageDescription）

- **用途**：用于将聊天中接收到的图片或文件保存至您的系统相册。
- **触发时机**：仅在您主动点击保存操作时请求。
- **数据来源**：仅保存来自您服务端的图片内容。

### 3.4 剪贴板

- **用途**：用于复制和粘贴文本内容，提升编辑效率。
- **方式**：通过 Tauri 官方剪贴板管理插件实现。
- **数据去向**：剪贴板数据仅在您的设备本地处理，不会自动读取或上传。

## 4. 网络通信

### 4.1 通信架构

本应用是一个纯粹的客户端应用，所有网络通信仅发生在以下两个端点之间：

- **您的 iOS 设备** ↔ **您自行部署的服务端**（由您配置的 hostBaseUrl）

### 4.2 通信方式

| 通信方式 | 用途 |
|---------|------|
| HTTP REST API | 用户认证、会话管理、文件操作、Git 操作、偏好设置同步等 |
| WebSocket（ws/wss） | 实时消息推送、会话状态更新、终端日志流等 |

### 4.3 通信内容

所有通过 HTTP 和 WebSocket 传输的数据均发送至您自行配置的服务端地址，包括：

- 登录认证请求（用户名、密码）
- API 请求携带的 Bearer Token（用于身份验证）
- 会话消息和 AI 编程交互内容
- 文件上传/下载内容
- Git 操作请求
- 偏好设置同步数据

**CodingNS 团队无法访问或截取上述任何通信内容。**

## 6. 数据安全

### 6.1 本地数据安全

- 所有本地数据通过 iOS 系统级别的应用沙盒机制保护。
- 其他应用无法访问本应用存储在 localStorage 和应用数据目录中的数据。
- 卸载本应用将清除所有本地存储的数据。

### 6.2 网络数据安全

- 本应用的所有网络请求均携带认证令牌（Bearer Token）以验证身份。
- 认证令牌具有有效期，过期后需要重新认证。
- 本应用的内容安全策略（CSP）仅允许与用户配置的服务端地址通信。

### 6.3 安全建议

- 建议您在配置服务端地址时使用 HTTPS 和 WSS 加密连接。
- 建议您定期更换服务端密码。
- "记住密码"功能会将登录凭证保存在本地存储中，请在信任的设备上使用此功能。
- 如不再使用本应用，建议卸载以清除所有本地数据。

## 8. 数据保留与删除

### 8.1 本地数据

- 所有本地数据在您卸载本应用时将被自动清除。
- 您可以在应用内通过清除登录状态来删除认证凭证。

- 服务端数据由您自行部署和管理，CodingNS 团队无法访问或控制。
- 如需删除服务端数据，请在您的服务端上自行操作。
