# macOS 桌面端一键构建命令

## 这份说明解决什么问题

这份说明给一台 macOS 机器一套可以直接执行的命令，用来把当前仓库里的桌面端编译出来。

先把丑话说前面：

- 当前项目的桌面端构建命令是 `corepack pnpm --dir apps/desktop build`
- 当前 [apps/desktop/src-tauri/tauri.conf.json](C:/Code/CodingNS/apps/desktop/src-tauri/tauri.conf.json) 里 `bundle.active` 已经打开
- 这意味着在 macOS 机器上执行 `corepack pnpm --dir apps/desktop build` 时，会同时走应用打包流程

## 使用前提

mac 机器上需要先有这几样东西：

- Xcode Command Line Tools
- Node.js 20 或更高版本
- Git
- 网络正常，能拉 npm 和 crates.io 依赖

如果机器上还没有装 Xcode Command Line Tools，先执行：

```bash
xcode-select --install
```

这一步是苹果自己的安装流程，第一次会弹系统安装框。这个过程别装疯卖傻地想全自动，苹果就不是这么设计的。

## 从零开始的一键构建

把下面命令里的 `REPO_DIR` 改成仓库在 mac 上的实际路径，然后整段执行：

```bash
/bin/bash -lc '
set -euo pipefail

export REPO_DIR="$HOME/CodingNS"

if ! command -v rustup >/dev/null 2>&1; then
  curl https://sh.rustup.rs -sSf | sh -s -- -y
fi

export PATH="$HOME/.cargo/bin:$PATH"

rustup default stable
rustup target add aarch64-apple-darwin x86_64-apple-darwin

corepack enable
corepack prepare pnpm@10.7.1 --activate

cd "$REPO_DIR"

pnpm install --frozen-lockfile
corepack pnpm --dir apps/desktop build

echo ""
echo "构建完成，产物目录："
ls -lah "$REPO_DIR/apps/desktop/src-tauri/target/release"
'
```

## 如果仓库依赖早就装好了，直接编译

这种场景只需要跑这一段：

```bash
/bin/bash -lc '
set -euo pipefail

export REPO_DIR="$HOME/CodingNS"
export PATH="$HOME/.cargo/bin:$PATH"

cd "$REPO_DIR"
corepack enable
corepack prepare pnpm@10.7.1 --activate
corepack pnpm --dir apps/desktop build
'
```

## 构建产物看哪里

默认先看这个目录：

```bash
ls -lah "$REPO_DIR/apps/desktop/src-tauri/target/release"
```

当前配置下，重点看这类产物：

- `apps/desktop/src-tauri/target/release/codingns-desktop`
- `apps/desktop/src-tauri/target/release/bundle/macos/*.app`
- `apps/desktop/src-tauri/target/release/bundle/dmg/*.dmg`

如果没有看到 `.dmg`，先不要怀疑人生，先看构建日志里是不是被签名、权限或 Xcode 环境卡住了。

## 常见失败点

### 1. `xcode-select` 或 Apple SDK 相关报错

先执行：

```bash
xcode-select -p
```

如果这里报错，说明 Xcode Command Line Tools 没装好，回去先装。

### 2. `cargo` 或 `rustc` 找不到

执行：

```bash
export PATH="$HOME/.cargo/bin:$PATH"
cargo -V
rustc -V
```

### 3. `pnpm` 或 `corepack` 不可用

执行：

```bash
corepack enable
corepack prepare pnpm@10.7.1 --activate
pnpm -v
```

### 4. 想打出 macOS 安装包

现在项目配置已经打开打包模式。只要在 macOS 机器上具备完整的 Xcode Command Line Tools 和 Apple 打包环境，执行构建命令后就应该在 `target/release/bundle/dmg/` 下面看到 `.dmg`。

## 最短可执行版本

如果那台 mac 机器已经装好了 Xcode Command Line Tools、Node、Rust，这就是最短命令：

```bash
export PATH="$HOME/.cargo/bin:$PATH" && cd "$HOME/CodingNS" && corepack enable && corepack prepare pnpm@10.7.1 --activate && corepack pnpm --dir apps/desktop build
```
