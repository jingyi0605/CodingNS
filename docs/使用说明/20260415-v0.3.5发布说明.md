# CodingNS v0.3.5 发布说明

## 功能更新

- 新增统一软件更新入口，支持桌面端客户端更新、Android `APK` 更新和服务端全局 `npm` 升级。
- 设置页新增模型管理，支持通过 `cc-switch` 快速切换 `codex`、`claude-code`、`gemini`、`opencode` 默认模型。
- 重构移动端主入口，对话页重新作为核心入口，文件、Git、助手和终端入口更清晰。
- 对话框支持任意文件附件上传，并补齐多端文件选择。
- 登录失败三次后新增图形验证码。

## Bug 修复

- 修复 Codex `fork`、子 agent 和 native fork 会话误继承父会话历史的问题。
- 修复会话终态识别过早、会话绑定竞态和 `turn_aborted` 消息显示异常。
- 修复 Butler 代办分析、执行会话回收和实时同步链路问题。
- 修复终端默认命名、创建顺序、标签排序以及 `tmux` 回显异常问题。
- 修复后端启动恢复阻塞 `ready` 的问题，并补齐 Tailscale 相关回归测试。
- 修复 macOS 会话菜单与 Git 最近版本菜单不一致的问题，统一为原生右键菜单。
- 修复多处设置页、模态框和夜间模式样式不统一问题。
