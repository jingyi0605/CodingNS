## 5. Skill 自动同步现状

| 场景 | 之前 | 现在 |
| --- | --- | --- |
| npm 包安装 | 不会自动安装 `codingns-assistant`，只校验 Codex SDK | 会把包内置的最新 `codingns-assistant` 同步到 `CODINGNS_CODEX_HOME` 或默认 `~/.codex/skills/codingns-assistant` |
| Host 服务启动 | 只有 Butler 自己的独立 Codex home 会按需同步 skill | Host 启动时会把内置 `codingns-assistant` 纳入 SSOT，并同步到 Host 配置对应的 Codex skill 目录 |
| Skill 真源 | 实际依赖开发机本地 `~/.codex/skills/codingns-assistant` | 仓库内置资源 `apps/host/src/modules/skills/builtin-skills/codingns-assistant` |

## 6. 当前结论

- `assistant` 现在不再只管“项目 / 会话 / 终端”，也正式覆盖“工作区 / 工作树”。
- `skills` 现在仍然只负责 Skill 扫描、导入和同步。
- `codingns-assistant` 已经按项目内置 skill 管理，CLI 和 skill 说明现在是一套语义。
